# 1.0.8

## 邮箱验证

- **注册需要邮箱验证**：注册时填写邮箱并获取验证码，验证通过才能创建账号
  （服务端开启邮箱强校验时生效）
- **忘记密码自助找回**：登录页新增「忘记密码？」，输入用户名后向绑定邮箱发送验证码，
  校验通过即可设置新密码；重置后其他设备上的登录会话全部失效
- **账户页可绑定 / 换绑邮箱**：「我的 → 绑定邮箱」，邮箱仅用于找回密码，不公开展示
- **老账号提醒**：已登录但未绑定邮箱的账号，首页顶部会出现一条提示，可一键前往绑定，
  也可以关闭（同一设备不再提示）

## 说明

- 邮箱验证由服务端配置；服务端未启用时，注册与找回流程自动隐藏，登录不受影响
- 一个邮箱只能绑定一个账号；绑定前会校验邮箱是否已被占用
