# 1.0.7

## 分享查看

- 分享查看升级为**独立页面**：顶部是分享者头像与用户名（点击可查看其公开主页），中部为在线预览，底部为文件信息与下载按钮
- 新增在线预览，覆盖常见类型：
  - 图片：双指缩放与拖动
  - 视频 / 音频：流式播放，边下边播
  - PDF：逐页翻阅
  - Markdown：渲染 / 原文一键切换
  - 代码与文本：语法高亮
- **下载统一进入传输中心**：进度、暂停、断点续传与普通传输任务完全一致，不再单独落盘
- 个人主页里的公开分享现在可直接打开分享详情页（此前只能转发原始链接）
- 粘贴分享链接的入口同样进入该详情页

## 说明

- 下载走传输中心后，分享文件的下载同样受「仅非计费网络」设置约束
- 预览由服务端内容嗅探把关：只有通过校验的类型才允许内联预览，可执行文件仍只能下载
